# מצא בזול

אתר הדגמה. כותבים משפט, והמנוע מחליט איפה לחפש: חדש אונליין, יד שנייה, או חנות מקומית. התשובה מציגה זו לצד זו התאמה, חלופה זולה יותר, חלופה מהירה יותר, וחלופה דומה. לכל אחת יש שורת הסבר: מה מתאים ומה מפסידים.

הסינון נשאר לפי קטגוריה. מידה וצבע מופיעים בבגדים, לא במוצרי חשמל.

הדפדפן שולח את החיפוש לשרת. הסיסמאות נשארות בסביבת השרת, לא בדפדפן ולא בריפו. אם חדש אונליין מתאים ויש סיסמה, השרת קורא למנוע קניות. אם יד שנייה מתאים ויש סיסמה, השרת קורא ל־eBay. בלי סיסמה לא יוצאת קריאה, והמחירים בכרטיסים נשארים דוגמה. לפייסבוק מרקטפלייס וליד2 מכינים נוסח חיפוש, בלי שליפת מחיר.

שמות משתני הסביבה שהשרת מחפש:

- `SERPAPI_API_KEY` — גוגל שופינג דרך SerpAPI
- `SEARCHAPI_API_KEY` — גוגל שופינג דרך SearchApi
- `DATAFORSEO_LOGIN` ו־`DATAFORSEO_PASSWORD` — גוגל שופינג דרך DataForSEO
- `EBAY_CLIENT_ID` ו־`EBAY_CLIENT_SECRET` — eBay
- `EBAY_MARKETPLACE_ID` — רשות. בלי זה השרת משתמש ב־`EBAY_US`

אם מוגדרים כמה מנועי קניות, השרת משתמש בראשון מהרשימה: SerpAPI, אחר כך SearchApi, אחר כך DataForSEO.

## הרצה

```bash
npm start
```

אפשר גם `npm run dev`. האותיות חייבות להיות קטנות. אחר כך פותחים בדפדפן את http://127.0.0.1:3000

ואז לפתוח את [http://localhost:3000](http://localhost:3000).
