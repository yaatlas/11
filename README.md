# מצא בזול

אתר הדגמה להשוואת קנייה. אפשר לכתוב משפט, לסנן, להקליט או להעלות תמונה. התוצאות מציגות חנויות ואתרים, עם דירוג וביקורות לדוגמה.

האיסוף רץ על קטלוג הדגמה ועל קובץ דיווחים. סריקה חיה של אתרי חנויות לא מחוברת: היא דורשת מקור שהאתר מרשה.

המחירים הם קטלוג לדוגמה. הם לא מגיעים מחנויות אמיתיות.

## הרצה

```bash
npm start
```

ואז לפתוח את [http://localhost:3000](http://localhost:3000).

## בדיקות

```bash
npm test
```
