# מצא בזול

אתר הדגמה להשוואת הצעות קנייה. שלב 2 מוסיף מנוע שמבין משפט חופשי: תקציב, משלוח, חדש בלבד, גודל, ולמה המוצר מתאים. הוא מדרג רק הצעות שעומדות בתנאים ומסביר את הבחירה.

המחירים הם קטלוג לדוגמה. הם לא מגיעים מחנויות אמיתיות.

## הרצה

```bash
npm start
```

ואז לפתוח את [http://localhost:3000](http://localhost:3000).

## בדיקות

```bash
npm test
```
