# מצא בזול

אתר הדגמה להשוואת הצעות קנייה. שלב 1 כולל חיפוש בעברית, מיון לפי מחיר כולל משלוח או מהירות או שילוב שלהם, רשימת מוכרים לאותו מוצר, ואפשרויות דומות.

המחירים הם קטלוג לדוגמה. הם לא מגיעים מחנויות אמיתיות.

## הרצה

```bash
npm start
```

ואז לפתוח את [http://localhost:3000](http://localhost:3000).

## בדיקות

```bash
npm test
```
